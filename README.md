## About

Code Memory Trainer helps users memorize code syntax while building typing muscle memory. Lessons combine theory, step-by-step drills, live code explanations, progress tracking, and a virtual keyboard.

### Current features

- Interactive code typing exercises
- Course → lecture → ordered sub-exercise structure
- Context-aware **CODE EXPLAIN**
- MySQL and JavaScript course content
- RU / EN / DE lecture languages
- Per-lesson progress saved locally
- Physical keyboard layout support
- Virtual keyboard with current-key highlighting
- Light / dark themes and music modes

## Tech

React · Vite · ASP.NET Core *(planned/backend integration)* · Docker · Steam SDK *(planned)*
